# Xenon

Xenon is a lightweight, yet advanced bot for Geometry Dash. 

## Features

- Record and replay levels
- CBF implementation
- Macro editor
- Built in calculator for frame windows
- Utilities to make botting easier

## Usage

- Press 'F' to open the menu
- Press 'V' to toggle frame stepper
- Press 'C' to advance 1 frame
